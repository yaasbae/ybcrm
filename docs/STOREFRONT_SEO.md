# SEO-центр YAASBAE

Реализация SEO-центра для штатного выпуска CRM. CRM: отдельная ветка `codex/storefront-seo-admin`, каталог `/private/tmp/ybcrm-seo-admin`.

## Возможности

В YBCRM → Магазин → SEO-центр: главная, каталог, список историй и опубликованные товары. Для каждой страницы доступны SEO title, description, H1, подпись главного фото, текст товара, внутренний целевой запрос и исключение из поиска. Название товара и цены в CRM не изменяются.

Сначала сохраняйте черновик, затем публикуйте. Сохраняются три предыдущие публикации; восстановление возвращает текст в черновик. Защита по версии не позволяет незаметно перезаписать правки другого администратора. Пустые поля используют данные товара и базовые тексты. Проверки заполнения и повторов — редакционные подсказки, не оценка позиции в поиске.

## Доступ и выдача

Приватный документ `settings/storefrontSeo` доступен только администраторам по существующим правилам Firestore. Публичный GET `/api/storefront/seo` отдаёт только опубликованные поля разрешённых страниц и видимых товаров, без черновиков, истории и внутреннего запроса. Новых публичных операций записи нет.

Магазин получает публикации через `/api/commerce/seo`. PHP на REG.RU добавляет метаданные в начальный HTML главной, каталога, списка историй и товаров. Клиент поддерживает их при переходах; H1 и описание товара используют опубликованный текст. Для товаров создаётся Product JSON-LD с реальной ценой и известным наличием. Личные страницы исключены из индексации. Динамический sitemap исключает noindex и непубличные товары. Канонические адреса формируются автоматически. Индивидуальный редактор SEO статей в этот этап не входит.

Серверный публичный кеш: 60 секунд, допустимый резерв при недоступности CRM — до 10 минут; устаревшие предложения старше 5 минут исключаются из разметки. При отсутствии каталога товары и sitemap отвечают 503, отсутствующий товар — 404. Изменения отображаются после обновления страницы и истечения кеша; это не мгновенный push в открытые вкладки.

## Проверки и публикация

Проверены черновики/публикация/история/конфликты, фильтрация приватных полей, неизвестное наличие, HTML-экранирование, метаданные, серверный HTML, sitemap и noindex. Добавлены проверки CI. Для CRM добавлен отрицательный тест прав доступа, требующий Firestore emulator.

Визуальная проверка desktop/mobile заблокирована автоматической проверкой доступа из-за лимита аккаунта. 25.10.2026 зафиксированные зависимости Functions/MCP установлены в рабочей копии; полная проверка типов CRM прошла. Основная и REG-сборка проходили в ходе разработки. Повторная REG-сборка после последних небольших правок дважды зависла до вывода Next.js и была остановлена; API-файлы восстановлены. Финальная сборка CRM и её отдельная проверка типов прошли. 18 Node-тестов магазина, 5 CRM SEO-тестов и PHP-проверки HTML/gateway прошли. 25.10.2026 отдельный тест Firestore emulator прошёл: гость и сотрудник не читают и не записывают SEO, администратор читает и записывает. Использованы временный Java runtime и локальный demo-проект; production-правила не менялись.

Порядок выпуска: проверить UI и отрицательные сценарии, согласовать публикацию CRM по AGENTS.md, выпустить CRM с публичным SEO endpoint, затем магазин. После выпуска проверить исходный HTML реального товара, 404, robots.txt и sitemap.xml на основном домене, убедиться в работе Apache rewrites при текущей конфигурации REG.RU. Реальные данные SEO в этой задаче не изменялись.

Откат: вернуть предыдущие версии CRM и магазина; приватный SEO документ совместим и может остаться. История конкретной страницы восстанавливается через черновик с повторной публикацией.
